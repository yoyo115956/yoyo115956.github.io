# 一、什么是计算机体系结构

计算机体系结构（Computer Architecture）是指计算机系统的**逻辑结构与功能特征**，是软件与硬件之间的接口规范。它定义了程序员（或编译器）所看到的机器：指令集、寄存器、数据类型、寻址方式等。

体系结构研究可以分为三个层次：

| 层次 | 英文 | 关注点 |
|------|------|--------|
| 指令集架构（ISA） | Instruction Set Architecture | 软硬件接口，指令编码 |
| 微架构（Microarchitecture） | Microarchitecture | 流水线、缓存、执行单元的具体实现 |
| 物理实现 | Physical Implementation | 晶体管、布局布线 |

---

# 二、指令集架构（ISA）

ISA 是 CPU 与软件之间的"合同"。同一 ISA 可以有不同的微架构实现（如 x86 有 Intel 和 AMD 的不同实现）。

## 2.1 ISA 的分类

**CISC（复杂指令集）**：x86 是典型代表
- 指令数量多，功能强大
- 单条指令可完成复杂操作（如 `MOVSB` 字符串拷贝）
- 变长指令编码

**RISC（精简指令集）**：ARM、RISC-V 是典型代表
- 指令数量少，格式固定
- 操作以 Load/Store 为主，运算在寄存器间完成
- 便于流水线设计

## 2.2 ISA 的主要组成

一个 ISA 通常包含：
- **寄存器文件**：通用寄存器数量（RV32I 有 32 个通用寄存器）
- **数据类型**：整数、浮点、向量
- **寻址模式**：立即数、寄存器、内存间接
- **指令格式**：操作码字段、源/目的寄存器字段
- **内存模型**：大小端、对齐要求、一致性模型
- **特权级**：用户态、内核态切换机制

# 三、微架构（Microarchitecture）

微架构是 ISA 的**具体硬件实现方式**，决定了处理器的实际性能。同一 ISA，不同微架构的性能可以相差数倍。

## 3.1 经典五级流水线

最基础的 RISC 流水线分为五个阶段：

```
IF → ID → EX → MEM → WB
取指   译码  执行  访存   写回
```

每个时钟周期，每级流水线同时处理一条不同的指令，理想情况下 CPI（每条指令周期数）= 1。

## 3.2 影响实际 CPI 的三种冒险

| 冒险类型 | 原因 | 解决方法 |
|----------|------|----------|
| 结构冒险 | 硬件资源冲突 | 增加资源（双端口寄存器文件）|
| 数据冒险 | 前后指令数据依赖 | 数据前递（Forwarding）、插入 stall |
| 控制冒险 | 分支跳转未知 | 分支预测、延迟槽 |

## 3.3 性能公式

$$
\text{执行时间} = \text{指令数} \times \text{CPI} \times \text{时钟周期}
$$

提升性能的三条路径：
1. **减少指令数**：更好的编译器、更强大的 ISA
2. **降低 CPI**：乱序执行、超标量、更好的分支预测
3. **提高主频**：工艺进步、更短的关键路径

# 四、现代高性能处理器关键技术

## 4.1 超标量（Superscalar）

每个周期发射多条指令，需要多个执行单元并行工作。现代处理器（如 Intel Core i9）可以每周期发射 4-6 条指令。

## 4.2 乱序执行（Out-of-Order Execution, OoO）

按照数据就绪顺序（而非程序顺序）执行指令，利用 ROB（重排序缓冲区）保证顺序提交，对程序语义透明。

## 4.3 分支预测（Branch Prediction）

现代处理器分支预测准确率超过 95%，包括：
- 静态预测（总预测跳转/不跳转）
- 两位饱和计数器
- 全局历史预测器（GShare、TAGE）

## 4.4 存储层次（Memory Hierarchy）

```
寄存器（<1ns）→ L1 Cache（~1ns）→ L2 Cache（~4ns）
→ L3 Cache（~10ns）→ DRAM（~60ns）→ 磁盘（>1ms）
```

# 五、学习路径建议

学习体系结构的推荐顺序：

1. **数字电路基础**：组合逻辑、时序逻辑、有限状态机
2. **单周期处理器**：理解 datapath 与控制逻辑
3. **五级流水线**：冒险处理与 forwarding
4. **Cache 设计**：直接映射、组相联、替换策略
5. **乱序执行**：Tomasulo 算法、ROB
6. **仿真工具**：gem5 建模与性能分析

推荐资料：
- Patterson & Hennessy《Computer Organization and Design: RISC-V Edition》
- Hennessy & Patterson《Computer Architecture: A Quantitative Approach》
- CMU 15-740 / ETH Computer Architecture 课程
