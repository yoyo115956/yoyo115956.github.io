> gem5 是学术界最广泛使用的计算机体系结构仿真框架，支持多种 ISA（x86、ARM、RISC-V）和 CPU 模型，是体系结构研究的标准工具。

# 一、gem5 简介

gem5 是一个**模块化、可扩展的计算机系统仿真器**，由 MIT、Michigan、Wisconsin 等高校长期维护。

## 1.1 gem5 的核心能力

| 能力 | 说明 |
|------|------|
| 多 ISA 支持 | x86, ARM, RISC-V, MIPS, SPARC, Power |
| 多 CPU 模型 | AtomicSimpleCPU, TimingSimpleCPU, O3CPU |
| 内存系统 | 多级 Cache, DRAM 模型（DRAMSim2）|
| 互连网络 | Garnet（NoC 仿真），经典总线 |
| 多核支持 | 缓存一致性（MESI, MOESI）|
| SE/FS 模式 | Syscall Emulation（用户态）/ Full System（含 OS）|

## 1.2 两种运行模式

| 模式 | 说明 | 用途 |
|------|------|------|
| SE（Syscall Emulation） | 只运行应用程序，系统调用由宿主机处理 | 快速，适合单程序性能分析 |
| FS（Full System） | 完整引导 OS，运行真实系统 | 准确，适合 OS/驱动/多核研究 |

# 二、安装与编译

## 2.1 依赖安装（Ubuntu）

```bash
sudo apt-get install -y \
    build-essential git m4 scons zlib1g zlib1g-dev \
    libprotobuf-dev protobuf-compiler libprotoc-dev \
    libgoogle-perftools-dev python3-dev python3 \
    libboost-all-dev pkg-config
```

## 2.2 获取源码

```bash
git clone https://github.com/gem5/gem5.git
cd gem5
```

## 2.3 编译（以 X86 为例）

```bash
# 编译 X86 架构的 gem5，使用 16 个并行任务
scons build/X86/gem5.opt -j16

# 其他架构
scons build/ARM/gem5.opt  -j16
scons build/RISCV/gem5.opt -j16

# 调试版本（速度慢，但有更多检查）
scons build/X86/gem5.debug -j16
```

编译选项说明：
- `gem5.opt`：优化版本，日常使用
- `gem5.debug`：调试版本，包含断言
- `gem5.fast`：最快版本，去掉调试信息

# 三、第一个仿真：Hello World

## 3.1 SE 模式运行 Hello World

```bash
# 编译测试程序（静态链接，避免库依赖问题）
cat > hello.c << 'EOF'
#include <stdio.h>
int main() {
    printf("Hello, gem5!\n");
    return 0;
}
EOF
gcc -static -o hello hello.c

# 运行仿真（最简配置）
build/X86/gem5.opt configs/example/se.py \
    --cmd=./hello
```

## 3.2 输出文件

```
m5out/
├── config.ini      # 完整配置参数（所有组件的设置）
├── config.json     # JSON 格式配置
├── stats.txt       # 统计数据（最重要！）
└── system.pc.com_1.terminal  # 程序输出
```

## 3.3 stats.txt 解读

```
# 关键统计项
sim_ticks                          # 仿真时钟周期（ps）
sim_insts                          # 执行的指令数
sim_ops                            # 执行的微操作数
system.cpu.cpi                     # 每指令周期数
system.cpu.ipc                     # 每周期指令数（IPC）
system.cpu.dcache.overallMissRate::total  # L1 DCache miss rate
system.cpu.icache.overallMissRate::total  # L1 ICache miss rate
system.l2cache.overallMissRate::total     # L2 Cache miss rate
```

# 四、配置系统（Python Script）

gem5 的核心是通过 **Python 脚本**配置仿真系统，灵活强大：

```python
# 一个最简单的 gem5 配置脚本
import m5
from m5.objects import *

# 创建顶层系统
system = System()
system.clk_domain = SrcClockDomain(
    clock='1GHz',
    voltage_domain=VoltageDomain()
)
system.mem_mode = 'timing'
system.mem_ranges = [AddrRange('512MB')]

# CPU
system.cpu = TimingSimpleCPU()

# 内存总线
system.membus = SystemXBar()

# L1 Cache
system.cpu.icache = Cache(
    size='32kB', assoc=4,
    tag_latency=2, data_latency=2, response_latency=2,
    mshrs=4, tgts_per_mshr=20
)
system.cpu.dcache = Cache(
    size='32kB', assoc=4,
    tag_latency=2, data_latency=2, response_latency=2,
    mshrs=4, tgts_per_mshr=20
)

# 连接 Cache 到总线
system.cpu.icache.mem_side = system.membus.cpu_side_ports
system.cpu.dcache.mem_side = system.membus.cpu_side_ports
system.cpu.icache_port = system.cpu.icache.cpu_side
system.cpu.dcache_port = system.cpu.dcache.cpu_side

# 中断控制器（x86 需要）
system.cpu.createInterruptController()
system.cpu.interrupts[0].pio = system.membus.mem_side_ports
system.cpu.interrupts[0].int_requestor = system.membus.cpu_side_ports
system.cpu.interrupts[0].int_responder = system.membus.mem_side_ports

# 内存控制器
system.mem_ctrl = MemCtrl()
system.mem_ctrl.dram = DDR3_1600_8x8()
system.mem_ctrl.dram.range = system.mem_ranges[0]
system.mem_ctrl.port = system.membus.mem_side_ports

# 连接系统到总线
system.system_port = system.membus.cpu_side_ports

# 加载程序
process = Process()
process.cmd = ['./hello']
system.cpu.workload = process
system.cpu.createThreads()

# 开始仿真
root = Root(full_system=False, system=system)
m5.instantiate()
print("Beginning simulation!")
exit_event = m5.simulate()
print(f'Exiting @ tick {m5.curTick()} because {exit_event.getCause()}')
```

# 五、常用参数速查

```bash
# 查看所有可用参数
build/X86/gem5.opt configs/example/se.py --help

# 常用参数
--cpu-type=DerivO3CPU        # 使用乱序执行 CPU
--caches                     # 启用 L1 Cache
--l2cache                    # 启用 L2 Cache
--l1d_size=64kB              # L1 DCache 大小
--l1i_size=32kB              # L1 ICache 大小
--l2_size=256kB              # L2 Cache 大小
--l1d_assoc=8                # L1 DCache 相联度
--mem-type=DDR4_2400_16x4    # 内存类型
--num-cpus=4                 # 多核数量（需配合 --ruby 或 --caches）

# 统计输出控制
--stats-file=my_stats.txt    # 自定义统计文件名
-r                           # 从 checkpoint 恢复
```
