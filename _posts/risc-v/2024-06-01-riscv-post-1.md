> RISC-V 是一个开源、模块化的精简指令集架构，正在成为学术研究和开源芯片设计的主流平台。

# 一、RISC-V 简介

RISC-V（读作 "RISC Five"）由加州大学伯克利分校于 2010 年发起，是第五代 RISC 研究项目的成果。与 x86、ARM 不同，RISC-V 是**完全开放、无版权费用**的 ISA，任何人都可以免费使用。

## 1.1 为什么选择 RISC-V

| 特性 | 说明 |
|------|------|
| 完全开源 | ISA 规范公开，无专利限制 |
| 模块化设计 | 基础 ISA + 可选扩展，按需裁剪 |
| 简洁优雅 | 基础整数指令集 RV32I 仅 47 条指令 |
| 学术友好 | 大量教材、工具链、开源实现 |
| 工业落地 | SiFive、阿里平头哥、算能等均有产品 |

## 1.2 版本与变体

| 变体 | 含义 |
|------|------|
| RV32I | 32 位地址空间，基础整数指令集 |
| RV64I | 64 位地址空间，基础整数指令集 |
| RV128I | 128 位（实验性） |
| RV32E | 嵌入式版本，只有 16 个寄存器 |

# 二、寄存器

## 2.1 通用整数寄存器

RV32I 共有 **32 个通用寄存器**（x0-x31），每个 32 位宽：

| 寄存器 | ABI 名称 | 用途 | 调用者保存? |
|--------|----------|------|-------------|
| x0 | zero | 硬连线为 0，写操作被忽略 | — |
| x1 | ra | 返回地址（Return Address） | 调用者 |
| x2 | sp | 栈指针（Stack Pointer） | 被调用者 |
| x3 | gp | 全局指针（Global Pointer） | — |
| x4 | tp | 线程指针（Thread Pointer） | — |
| x5-x7 | t0-t2 | 临时寄存器 | 调用者 |
| x8 | s0/fp | 保存寄存器 / 帧指针 | 被调用者 |
| x9 | s1 | 保存寄存器 | 被调用者 |
| x10-x11 | a0-a1 | 函数参数 / 返回值 | 调用者 |
| x12-x17 | a2-a7 | 函数参数 | 调用者 |
| x18-x27 | s2-s11 | 保存寄存器 | 被调用者 |
| x28-x31 | t3-t6 | 临时寄存器 | 调用者 |

**x0 永远为 0** 是 RISC-V 设计的精妙之处：许多"伪指令"都通过 x0 实现，例如：
```assembly
mv  rd, rs    →  addi rd, rs, 0     # 数据移动
li  rd, imm   →  addi rd, x0, imm  # 加载立即数
nop           →  addi x0, x0, 0    # 空操作
j   offset    →  jal  x0, offset   # 无返回值跳转
```

## 2.2 程序计数器

`pc`：32 位，保存当前指令地址。RISC-V 中 pc 不在通用寄存器范围内，无法直接读写（除通过 `auipc` 指令）。

# 三、指令格式

RV32I 所有指令均为**固定 32 位宽**，共 6 种格式：

```
31        25 24    20 19    15 14  12 11      7 6      0
┌───────────┬────────┬────────┬──────┬─────────┬────────┐
│  funct7   │  rs2   │  rs1   │funct3│   rd    │ opcode │  R型（寄存器-寄存器运算）
├───────────┴────────┤        │      │         │        │
│      imm[11:0]     │  rs1   │funct3│   rd    │ opcode │  I型（立即数/Load）
├───────────┬────────┤        │      │         │        │
│  imm[11:5]│  rs2   │  rs1   │funct3│imm[4:0] │ opcode │  S型（Store）
├──────┬────┴────────┤        │      │    ┌────┤        │
│im[12]│  imm[10:5] │  rs2   │  rs1 │funct3│im[4:1]│im[11]│ opcode │  B型（分支）
├──────┴────────────────────────┐    │         │        │
│         imm[31:12]            │    │   rd    │ opcode │  U型（长立即数）
└───────────────────────────────┘    └─────────┴────────┘
```

# 四、基础指令集（RV32I）分类

## 4.1 算术逻辑指令（R 型）

```assembly
add  rd, rs1, rs2    # rd = rs1 + rs2
sub  rd, rs1, rs2    # rd = rs1 - rs2
and  rd, rs1, rs2    # rd = rs1 & rs2
or   rd, rs1, rs2    # rd = rs1 | rs2
xor  rd, rs1, rs2    # rd = rs1 ^ rs2
sll  rd, rs1, rs2    # rd = rs1 << rs2[4:0]
srl  rd, rs1, rs2    # rd = rs1 >> rs2[4:0]（逻辑右移）
sra  rd, rs1, rs2    # rd = rs1 >>> rs2[4:0]（算术右移）
slt  rd, rs1, rs2    # rd = (rs1 < rs2) ? 1 : 0（有符号比较）
sltu rd, rs1, rs2    # rd = (rs1 < rs2) ? 1 : 0（无符号比较）
```

## 4.2 立即数指令（I 型）

```assembly
addi rd, rs1, imm    # rd = rs1 + sign_ext(imm[11:0])
andi, ori, xori      # 同上，位运算
slli, srli, srai     # 移位，imm 为移位量
slti, sltiu          # 比较
```

## 4.3 Load / Store 指令

```assembly
lw   rd, offset(rs1)  # 从内存加载 32 位字（有符号扩展）
lh   rd, offset(rs1)  # 加载 16 位半字
lb   rd, offset(rs1)  # 加载 8 位字节
lhu, lbu              # 无符号版本

sw   rs2, offset(rs1) # 存储 32 位
sh   rs2, offset(rs1) # 存储 16 位
sb   rs2, offset(rs1) # 存储 8 位
```

## 4.4 分支指令（B 型）

```assembly
beq  rs1, rs2, offset  # if rs1 == rs2: PC += sign_ext(offset)
bne  rs1, rs2, offset  # if rs1 != rs2
blt  rs1, rs2, offset  # if rs1 < rs2（有符号）
bge  rs1, rs2, offset  # if rs1 >= rs2（有符号）
bltu, bgeu             # 无符号版本
```

## 4.5 跳转指令

```assembly
jal  rd, offset        # rd = PC+4; PC += sign_ext(offset)（±1 MB 范围）
jalr rd, rs1, offset   # rd = PC+4; PC = (rs1 + offset) & ~1（间接跳转）
```

## 4.6 长立即数指令（U 型）

```assembly
lui   rd, imm   # rd = imm << 12（加载 20 位立即数到高位）
auipc rd, imm   # rd = PC + (imm << 12)（PC 相对寻址）
```

# 五、扩展模块

| 扩展 | 字母 | 内容 |
|------|------|------|
| 整数乘除 | M | `mul`, `div`, `rem` |
| 原子操作 | A | `lr.w`, `sc.w`, `amoswap` 等 |
| 单精度浮点 | F | IEEE 754 单精度 |
| 双精度浮点 | D | IEEE 754 双精度 |
| 压缩指令 | C | 16 位压缩指令（代码密度优化） |
| 向量扩展 | V | SIMD 向量运算 |

常见组合：
- `RV32IMAC`：嵌入式常用组合
- `RV64GC`（G = IMAFD）：Linux 系统常用组合

# 六、第一个 RISC-V 汇编程序

```assembly
# 计算 1+2+...+10
.text
.globl _start
_start:
    li   t0, 0    # sum = 0
    li   t1, 1    # i = 1
    li   t2, 10   # n = 10
loop:
    add  t0, t0, t1   # sum += i
    addi t1, t1, 1    # i++
    ble  t1, t2, loop # if i <= n: goto loop
    # 结果在 t0 中 = 55
```

推荐工具：[RISC-V Venus 在线模拟器](https://venus.cs61c.org/) 可以直接在浏览器中运行 RISC-V 汇编。
