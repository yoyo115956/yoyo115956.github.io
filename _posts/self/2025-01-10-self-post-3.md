> 记录我拿到海光信息 offer 的全流程，以及在与同学交流中总结的芯片求职经验。

# 一、整体时间线

芯片企业秋招一般比互联网晚 1-2 个月：

| 时间 | 节点 |
|------|------|
| 3-6 月 | 春招（部分企业）、实习转正 |
| 7-8 月 | 暑期实习 / 实习转正 |
| 9-10 月 | 秋招笔试高峰期 |
| 10-12 月 | 技术面试、HR 面 |
| 12 月-次年 1 月 | Offer 发放 |

主要招聘平台：
- 牛客网（芯片岗最集中）
- 企业官网招聘（海光、寒武纪、华为海思、龙芯等）
- 学校就业网/导师推荐（最快最稳）

# 二、投递策略

## 2.1 梯度投递

把目标企业分成三档：
- **冲刺档**（TOP 5 意向）：海光、华为海思、英伟达、AMD、ARM 中国
- **主力档**（5-10 家）：寒武纪、地平线、平头哥、兆芯、中科驭数
- **保底档**（5-10 家）：各地中小型芯片公司、晶圆厂验证岗

**关键建议**：不要只盯着大厂。国内中小型芯片公司的验证岗位，对于积累实战经验同样有价值，而且竞争没那么激烈。

## 2.2 岗位匹配度

芯片验证细分方向很多，投递前确认匹配：
- 前端仿真验证（你的核心方向）
- 形式验证（需要额外准备 SVA/JasperGold）
- FPGA 原型验证（需要 FPGA 经验）
- 系统集成验证（更偏 SoC 级别）

# 三、笔试准备

## 3.1 数字逻辑与电路基础

这是所有芯片公司笔试的必考项：

**高频考点**：
- 组合逻辑：卡诺图化简、多路复用器实现逻辑函数
- 时序电路：D 触发器的 Setup/Hold Time 计算
- 最大工作频率：$f_{max} = \frac{1}{T_{clk\_min}}$，$T_{clk\_min} = t_{setup} + t_{c-q} + t_{comb}$
- 亚稳态：产生原因、同步器设计、MTBF 计算
- 异步 FIFO：格雷码指针，空满判断逻辑

**典型计算题**：
```
已知：触发器 Tco = 0.5ns，组合逻辑最大延迟 Tcomb = 3ns，
     Setup Time = 0.5ns，Hold Time = 0.2ns
问：该电路最高工作频率是多少？
答：Tclk_min = Tco + Tcomb + Tsetup = 0.5+3+0.5 = 4ns → fmax = 250MHz
```

## 3.2 Verilog/SystemVerilog 编程

笔试通常要求手写代码，重点：
- 编写基础 RTL：计数器、移位寄存器、FSM
- 异步 FIFO 完整实现
- 简单 UVM component（写出框架即可）

```verilog
// 常考：用 always 实现 Moore FSM
module fsm_1011 (
    input  wire clk, rst, in,
    output reg  detected
);
    typedef enum logic [1:0] {S0, S1, S10, S101} state_t;
    state_t state, next;
    
    always @(posedge clk or posedge rst)
        state <= rst ? S0 : next;
    
    always @(*) begin
        case (state)
            S0:   next = in ? S1 : S0;
            S1:   next = in ? S1 : S10;
            S10:  next = in ? S101 : S0;
            S101: next = in ? S1 : S10;
        endcase
    end
    
    assign detected = (state == S101) && in;  // Mealy 输出
endmodule
```

## 3.3 协议知识

- AXI4 各通道握手规则（背熟 AMBA Spec 第 4 章）
- AHB/APB 时序图（能手画信号波形）
- 至少了解一种高速接口：PCIe、DDR4、USB

# 四、技术面（1-3 轮）

## 4.1 第一轮：基础知识考察

通常 30-60 分钟，考察：
- 自我介绍（2-3 分钟，重点说项目经历）
- 数字电路基础问答（Setup/Hold、CDC、亚稳态）
- 协议问答（AXI 握手、outstanding 传输）
- 验证基础（UVM 各组件职责、覆盖率类型）

**面试技巧**：遇到不确定的问题，不要乱猜。可以说"我目前理解是……但这点我不太确定，我来推导一下"——展示思考过程比背标准答案更重要。

## 4.2 第二轮：项目深挖

重点讲你简历上的项目：
- 验证对象的具体功能是什么？
- 你负责哪个模块/哪类测试？
- 遇到过什么 Bug？是什么现象？你怎么定位的？
- 覆盖率最终达到多少？有哪些 bin 是特别难覆盖的？

**准备方法**：把自己的项目经历写成 3-5 页的 PDF，每个项目：背景→你的工作→遇到的挑战→结果。面试前反复讲给朋友听，能流利地讲 10 分钟。

## 4.3 第三轮（如有）：设计题/方案设计

- 给你一个 DUT（如一个简单 UART 控制器），要求设计验证方案
- 画出 UVM 环境框图
- 描述 sequence、scoreboard 的设计思路
- 列出覆盖率 model

---

# 五、HR 面

主要考察：
- **求职动机**：为什么选择芯片行业？为什么选择我们公司？
- **职业规划**：3-5 年的目标是什么？
- **性格与适应性**：能接受加班吗？愿意出差/搬迁吗？
- **薪资期望**：提前了解行情，给出有竞争力但不虚高的数字

---

# 六、薪资参考（2024-2025 届，仅供参考）

| 公司类型 | 硕士应届薪资范围（税前年薪）|
|----------|---------------------------|
| 头部（海思/英伟达/AMD）| 50-80 万 |
| 腰部（海光/寒武纪/地平线）| 30-50 万 |
| 中小公司 | 20-35 万 |

芯片行业薪资整体低于互联网大厂，但稳定性更好，且行业成长空间更大。

# 七、写给后来者

求职本质上是一个**供需匹配**的过程：你能提供什么价值，公司在找什么人。

准备期间：
1. 把基础知识点系统梳理一遍（不要只刷面经，要理解原理）
2. 项目经历要能讲得清楚、讲得深
3. 广投，不要把希望都押在一家公司上
4. 面试后及时复盘，记录不会的问题，补上知识漏洞

最后，保持平常心。offer 拿到了，只是一个开始。
